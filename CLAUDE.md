## Repository Overview

This is a hardware documentation repository for **picobox**, a device based on the Raspberry Pi Pico (or similar RP2040-based board). The repository contains no source code — it consists entirely of Korean-language reference images.

## Contents

- `기본사용법.png` — Basic usage diagram
- `핀배치.png` — Pin layout / pinout diagram

## Nature of Contributions

Since this is a documentation-only repository, contributions are limited to updating the README or replacing/adding reference images. There are no build steps, linters, or test suites to run.
